# Distance Calculator
### A Simple Python Program to Compute 2D Distance


---

## 1. Project Overview

### Purpose of Code
The purpose of this program is to calculate the distance between two points using Python's built-in math library.

### Key Improvements in Revised Work
* Added comments throughout the code.
* Added a feature to round up the final distance calculation.

---

## 2. Program Details

### Input Needed
The program requires four numeric inputs from the user:
1. x1: X-coordinate of Point 1
2. y1: Y-coordinate of Point 1
3. x2: X-coordinate of Point 2
4. y2: Y-coordinate of Point 2

### Sample Output
text:
Enter x1: 2 
Enter y1: 3 
Enter x2: 7 
Enter y2: 8 
Distance is: 7.07
